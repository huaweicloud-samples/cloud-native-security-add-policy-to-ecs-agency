This reference architecture periodically scans ECS instances in a project, ensures their attached IAM agencies carry the system policies required for host monitoring and log reporting, and provides an entry point for associating a target agency to instances that have none (this optional capability requires a runtime implementation tailored to the target environment before it can be enabled). It targets cloud operations and security teams as an account-level governance baseline.
